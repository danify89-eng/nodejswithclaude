Beginner guide

Build your website by just asking.

This page shows how to use Claude Code with the WebPros MCP connection to create a website and put it live on your cPanel hosting. You type plain-English requests, and Claude does the technical work for you.

  • ⏱ About 20 minutes
  • 💻 No coding needed
  • 🌐 Works with cPanel hosting

What you'll do

  1. Check you have what you need
  2. Open Claude Code
  3. Sign in to WebPros MCP
  4. Check the connection
  5. Make a folder for your site
  6. Ask Claude to build the website
  7. Open your live website
  8. Make changes any time
  9. Good to know (limits)

Before you start

You need these four things:

  • A cPanel hosting account with a domain, such as yourshop.com.
  • A Claude account that can use Claude Code.
  • Claude Code, either the VS Code extension or the terminal app.
  • The WebPros MCP server added to Claude Code. Your hosting provider or WebPros gives you the setup details.
What is "MCP"? MCP is a safe bridge that lets Claude talk to other services. The WebPros MCP lets Claude look inside your cPanel hosting and work on it: it can read and save files, check your domains, and more. It only works after you sign in and give permission.
1

Open Claude Code

Start Claude Code the way you normally do:

  • VS Code: click the Claude icon in the sidebar to open the chat panel.
  • Terminal: open a terminal and type:
claude
2

Sign in to WebPros MCP

Claude can't use your hosting until you sign in. In the Claude Code chat, type:

/mcp

A list of connections appears. Choose webpros-mcp, pick Authenticate, and finish signing in in the browser window that opens.

Never paste passwords into the chat You sign in on the official login page in your browser. Claude never needs your cPanel password, codes or tokens typed into the chat.
3

Check the connection

Ask Claude in plain words:

"Am I connected to WebPros MCP?"

If it works, Claude replies with the name of your hosting server. For example:

Yes, you're connected. It can reach one cPanel server:
vmi3118027.contaboserver.net

If Claude says the server needs authorization, go back to Step 2.

4

Make a folder for your site

Every folder you create inside public_html becomes a web address. For example, a folder named shop becomes yourdomain.com/shop/.

Create the folder yourself (about 30 seconds) The WebPros MCP can read and save files, but it has no "create folder" option. Make the folder by hand:
  1. Log into cPanel and open File Manager.
  2. Open the public_html folder.
  3. Click + Folder, type a short name like shop, and click Create.

Tip: use lowercase letters with no spaces. The name is only part of the web address. It doesn't change how the site works.

5

Ask Claude to build the website

Tell Claude what you want, where to put it, and who it's for. The more you describe, the better the result. Some example requests:

"Build me a website in https://yourdomain.com/shop/. It's a small online shop selling handmade candles. I want a home page, a product list with prices, and a contact section. Use warm colours."
"Make a one-page website in https://yourdomain.com/portfolio/ that shows my photography, with a short 'about me' and my email."
"Create a 'Coming Soon' page in https://yourdomain.com/launch/ with my business name and a countdown to 1 December."

Claude will then:

  1. Find your domain and the folder you made.
  2. Check that nothing already in the folder gets overwritten.
  3. Write the website files and save them straight onto your hosting.
  4. Give you the link to open.
Claude checks with you first Before anything risky, like replacing an existing file, Claude stops and asks you.
6

Open your live website

Open the link in any browser, on your computer or your phone. Your site is live, and anyone with the link can see it.

If you see an old version, refresh the page. On a computer, press Ctrl + F5 (Windows) or Cmd + Shift + R (Mac).

7

Make changes any time

You don't need to edit any code. Just ask:

"On my shop page, change the main colour to dark green and add a new product: Lavender Candle, $18."
"Make the text bigger on phones."
"Add my Instagram link at the bottom."

Claude reads the current file from your hosting, makes the change, and saves it back.

Good to know

TopicWhat happens
New foldersClaude can't create them through the MCP. Make them in cPanel File Manager (Step 4).
Big files (over 64 KB, like large photos)These go straight to your server over a secure connection. Claude uses a temporary access key for this and deletes it as soon as the upload finishes.
What kind of websiteNormal cPanel hosting runs HTML, CSS, JavaScript and PHP with a MySQL database. That covers shops, blogs, portfolios and contact forms. It can also run Node.js apps (like this page) once your host installs Node.js and turns on Application Manager in cPanel.
Your other filesClaude lists what's in a folder before writing, so your existing site isn't overwritten without asking.
SafetyClaude only gets access after you sign in with /mcp. You can sign out at any time from the same menu.

Questions

Do I need to know how to code?

No. You describe what you want in normal words, and Claude writes the code and puts it on your hosting.

Claude says "webpros-mcp needs authorization". What do I do?

Type /mcp in Claude Code, select webpros-mcp, and sign in again in your browser. Then ask "Am I connected now?"

Can I have more than one website on one domain?

Yes. Each folder inside public_html is its own site, for example /shop/, /blog/ and /launch/.

What if I don't like the result?

Tell Claude what to change, such as "make it simpler", "use blue instead" or "remove the prices". You can keep asking until it looks right.

Can Claude delete my files?

Claude won't delete or replace your files without asking you first. A backup is still a good idea: in cPanel, use Backup to download a copy of your site.
